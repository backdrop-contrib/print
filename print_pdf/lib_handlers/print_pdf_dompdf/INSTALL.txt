dompdf support:
  The dompdf tool produces results that are more faithful to the HTML
  printer-friendly page. Good support of CSS 2.1 and partially CSS3.

  Use a version of this tool that is 0.8.2 or newer since it is fully
  compatible with PHP 7.1, and this module no longer supports older versions.
  The latest version as of this writing is 3.x.

  Current version:

  There are two approaches. Either install with Composer, or download the full
  release zipfile with the version number in the filename.

  Composer:

  1. Install with Composer. Print module will scan a `libraries` directory in the
  web root.
  2. To install run: `composer require dompdf/dompdf` from the `libraries`
  directory.

  Zipfile:

  1. Download dompdf from https://github.com/dompdf/dompdf/releases. Make sure
  to download the full release zipfile. Choose the highest version that will
  work with your host.
  2. Extract the contents of the downloaded package into one of the
  supported paths, such as `libraries` in the webroot.

  General steps:
  1. Grant write access to the lib/fonts directory for your webserver user.
  2. Review the recommendations for securing your dompdf installation at
  https://github.com/dompdf/dompdf/wiki/Securing-dompdf
  3. Check https://dompdf.github.io/ for further information.
